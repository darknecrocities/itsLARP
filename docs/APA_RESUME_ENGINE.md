# APA 7th Edition Resume & CV Engine

## Overview

**itsLARP / HowToLarped** includes an engine for compiling **Curriculum Vitae and Resumes formatted according to the American Psychological Association (APA) 7th Edition** standard.

This format provides clear, academic, and verifiable documentation of technical accomplishments, eliminating inflated buzzwords in favor of rigorous, evidence-backed software citations.

---

## 1. APA 7th Edition Formatting Rules

### 1.1 Running Head & Page Header
In accordance with APA 7th guidelines:
- The running head appears in the top header:
  `RUNNING HEAD: SURNAME / CURRICULUM VITAE`
- The page number is right-aligned (`Page 1`, `Page 2`).
- Set in standard 10pt–12pt serif or monospace typography.

### 1.2 Title Block (Centered)
The title block is centered at the top of the page:
1. **Candidate Full Name** (Bold, 18pt serif)
2. **Professional Headline / Specialization** (Italic, 13pt serif)
3. **Contact & Verification Details** (Email, Geographic Location, GitHub, LinkedIn)

### 1.3 Section Headings (APA Level 1)
All primary section headings are **Centered, Bold, Title Case**:
- `Professional Abstract`
- `Academic Preparation and Credentials`
- `Technical Competencies and Frameworks`
- `Professional Practice`
- `Software Artifacts and Project Contributions`
- `Verifiable Evidence Corpus`

## 2. Software Artifacts Citation Standard

Unlike standard bullet points ("Worked on backend microservices"), APA 7th Edition uses formal **Computer Software & Technical Work referencing**:

$$\text{Format: } \textbf{Author, A. A.} \text{ (Year). } \textit{Title of work} \text{ [Computer software / Tech Stack]. Publisher/URL.}$$

### Example Citations Generated by itsLARP:

```
Doe, J. (2026). Autonomous Multi-Agent Workforce [Computer software / Python, Redis, FastAPI].
    High-throughput distributed task runner coordinating 1,000 parallel workers with 0% hallucination guarantees.

Doe, J. (2025). Evidence-Backed Career DNA OS [Computer software / TypeScript, Next.js, PostgreSQL].
    Unified career operating system with deterministic 6-factor compatibility scoring.
```

## 3. Interactive Studio & Download Formats

In [Resume Studio](file:///Users/arronkianparejas/itsLarper/apps/web/app/resume/page.tsx), candidates can:
1. **Toggle Formats**: Switch between the *Modern Card View* and the *APA 7th Edition Paper View*.
2. **Download Plaintext (`.txt`)**: 
   Click `[ Download APA (.txt) ]` to save a 72-column aligned plaintext document ready for upload into traditional ATS systems.
3. **Download / Print to PDF**:
   Click `[ Print / Save PDF ]` to trigger the browser's print dialog. The built-in `@media print` stylesheet automatically formats 1-inch margins, Letter size, page breaks, and hides navigation headers.
4. **Download Tailored Versions**:
   Every tailored resume drafted for a specific job can also be downloaded in APA format!

## 4. Backend Generator Service

The engine is implemented in [`apps/api/services/apa_resume.py`](file:///Users/arronkianparejas/itsLarper/apps/api/services/apa_resume.py):

- `generate_apa_text(profile: dict) -> str`: Returns 72-column formatted plaintext.
- `generate_apa_html(profile: dict) -> str`: Returns print-ready HTML with Times New Roman typography and `@page` rules.

### Endpoints
- `POST /profile/apa-resume`: Returns both JSON text and HTML representations.
- `GET /profile/apa-resume/download?format=txt`: Direct browser attachment download.
- `GET /profile/apa-resume/download?format=html`: Standalone printable HTML page.
